# AI Workload Platform

一个面向 AI 与数据任务的可靠工作流编排和执行平台。

项目当前处于需求与架构设计阶段，尚未开始业务代码开发。新窗口或新会话第一次接触本项目时，请先阅读 [新窗口启动协议](docs/新窗口启动协议.md)，再按其中的顺序阅读核心文档：

1. [`项目状态.md`](项目状态.md)：当前进度、已批准范围和下一步工作。
2. [`docs/产品/产品说明.md`](docs/产品/产品说明.md)：项目解决什么问题，以及什么情况下值得使用。
3. [`docs/架构/架构基线.md`](docs/架构/架构基线.md)：系统由哪些部分组成。
4. [`docs/学习/学习资料规范.md`](docs/学习/学习资料规范.md)：学习资料的编写和使用方式。
5. [`docs/计划/项目路线图.md`](docs/计划/项目路线图.md)：项目阶段和每阶段验收目标。
6. 当前模块的详细计划、学习资料、代码和测试：根据 [`docs/新窗口启动协议.md`](docs/新窗口启动协议.md) 的当前模块结果读取；模块尚未拥有某类文件时，必须明确报告缺失。
