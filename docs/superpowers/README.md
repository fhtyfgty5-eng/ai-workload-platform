# 历史过程文档

`docs/superpowers/` 保存项目早期的规格说明和实施计划，包括当时的需求讨论、TDD 拆分、失败记录和验收过程。

这些文件的作用是保留决策和实现历史，不是当前项目状态或当前技术方案的唯一来源。阅读新窗口或复习当前项目时，应优先使用：

1. [`项目状态.md`](../../项目状态.md)：当前阶段、已完成内容、验证事实和下一步；
2. [`产品说明`](../产品/产品说明.md)：产品目标、用户和范围；
3. [`架构基线`](../架构/架构基线.md)：当前组件职责和数据流；
4. [`项目路线图`](../计划/项目路线图.md)：当前模块路线和验收边界；
5. 当前模块的需求与设计、实验报告和学习文章。

历史计划中出现的旧模块状态、旧命令或旧路线，表示它们在当时的记录，不应直接当作当前事实。若历史记录与当前文档不一致，以当前文档和代码验证结果为准。
