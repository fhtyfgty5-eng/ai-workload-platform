# 博客专栏规则实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task after user approval. Do not commit; the user commits manually after reviewing the diff.

**Goal:** 固化专栏定位、文章分类、正文边界和新窗口检查规则，避免后续文章再次混入项目管理内容或丢失项目定位。

**Architecture:** 以 `docs/学习/学习资料规范.md` 作为文章规则的唯一详细来源，`docs/学习/CSDN发布模板.md` 提供三类文章的可复制骨架，`docs/新窗口启动协议.md` 只保留接手检查项，`项目状态.md` 记录发布状态和专栏信息。

**Tech Stack:** Markdown；现有 Bash 文档验证器；Git `diff --check`。

## Global Constraints

- 专栏名称统一为“从0构建AI Workload Platform工程实践”。
- 博客正文不得包含 Codex 交接、仓库维护、Git 过程或文档验收输出。
- 项目总览篇、技术学习篇、模块实践篇职责必须分开。
- 技术学习篇保留面向零背景读者的详细术语、类比、示例、失败场景和替代方案。
- 发布状态和 CSDN 地址只记录在 `项目状态.md`，不放入文章正文。
- 本次只更新规则，不重写两篇文章正文，不进入模块 1。
- 不执行 `git add` 或 `git commit`。
